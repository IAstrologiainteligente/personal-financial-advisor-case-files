# Synthetic Financial Case Files

This repository contains self-created, synthetic financial materials prepared for professional finance exercises. All entities, transactions, names, dates, and amounts in the case files are fictional.

## Collections

### Personal Financial Advisor Case Files

The five spreadsheets in the repository root contain illustrative personal financial planning assumptions:

1. Credit Card Payment Schedule.xlsx
2. Card Bill Reconciliation.xlsx
3. Monthly Cash Flow Forecast.xlsx
4. Housing and Mortgage Assumptions.xlsx
5. Variable Income and Tutoring Assumptions.xlsx

### Northstar Treasury Case Files

The [Northstar Treasury Case Files](northstar-treasury-case-files/) folder contains 13 resources for a corporate treasury and 13-week liquidity forecasting exercise. Its [resource-specific license page](northstar-treasury-case-files/LICENSE.md) identifies every covered file and the applicable permissions.
