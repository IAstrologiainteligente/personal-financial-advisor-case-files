# Personal Financial Advisor Case Files

This repository contains anonymized, self-created financial planning materials. The files were prepared specifically for a Personal Financial Advisor task and are shared as reusable example material.

## About these files

The spreadsheets hold illustrative figures and planning assumptions only. They do not contain third-party copyrighted data, employer documents, bank statements, platform records, or any personally identifying information. Every value was made up for the purpose of the exercise.

## Files

1. Credit Card Payment Schedule.xlsx
2. Card Bill Reconciliation.xlsx
3. Monthly Cash Flow Forecast.xlsx
4. Housing and Mortgage Assumptions.xlsx
5. Variable Income and Tutoring Assumptions.xlsx
